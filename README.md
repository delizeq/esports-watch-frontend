# Esports Watch

Невеликий сайт для перегляду кіберспортивних матчів.

## Що є на сайті

- список матчів;
- фільтр за датою;
- інформація про команди, турніри та час початку матчу;
- статус матчу.

Сайт отримує дані з Django REST API.

## Запуск

1. Запусти Django API у папці бекенду:

   `python manage.py runserver`

2. У папці фронтенду запусти локальний сервер:

   `python -m http.server 5500`

3. Відкрий у браузері:

   `http://127.0.0.1:5500`

Перед запуском потрібно встановити залежності бекенду та виконати міграції.

## Технології

- HTML
- CSS
- JavaScript
- Django REST Framework
